# 增量 ETL 实现记录

## Watermark 规则

每个 `city + dataset` 维护独立 watermark。未显式传入日期时，起点为最后成功时间戳的下一小时，终点为当前 UTC 日期的前一天；首次运行默认回看 7 天。显式时间窗口用于回填或复现。

成功写入且质量检查未失败后才推进 watermark。没有新时间范围时记录 `NO_DATA`，不会发起无效 API 请求。

## 幂等策略

Clean 层以 `city + timestamp` 去重。即使显式重复请求同一范围，第二次写入也只统计为 skipped，不新增数据。Parquet 采用临时文件替换，避免半写入文件暴露给查询端。

## 真实运行证据

2026-09-30 对北京、上海、广州、深圳、东京、大阪执行 2026-09-23 至 2026-09-29 的真实采集：

| 运行 | fetched | inserted | skipped | 结果 |
|---|---:|---:|---:|---|
| 首次显式窗口 | 2016 | 2016 | 0 | 12 个城市/数据集任务成功 |
| 重复相同窗口 | 2016 | 0 | 2016 | 幂等去重成功 |
| 默认增量 | 0 | 0 | 0 | 12 个任务均为 NO_DATA |

最终 Clean 层包含 1008 条天气记录和 1008 条空气质量记录；合并视图包含 1008 条小时记录。
