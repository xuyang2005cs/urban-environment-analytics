# 数据质量设计

质量检查在标准化后、Clean 层写入前执行。当前检查保持轻量并适合小时级公开环境数据：

- schema：必要字段是否存在；
- completeness：行数、空值数和关键列空值比例；
- uniqueness：`city + timestamp` 重复数量和比例；
- temporal：时间戳可解析、单调、基本唯一，并统计明显时间缺口；
- validity：数值转换失败数量；
- range：温度、湿度、降水、风速、气压和污染物的合理边界。

缺失必要字段、无有效行或关键字段不可解析记为 FAIL；少量空值、重复或时间缺口记为 WARN；其余为 PASS。每次结果写入 `quality_runs`，Dashboard 展示最新状态和历史运行，但不会把 WARN 伪装成成功。

这些范围检查用于发现采集和结构问题，不代表医学或监管标准判断。
