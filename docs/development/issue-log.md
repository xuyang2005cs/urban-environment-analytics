# 真实问题记录

## 1. Windows 依赖安装文件锁

**现象：** 首次安装 Plotly 时出现 `WinError 32`，临时文件被另一进程占用。

**原因：** Windows 文件句柄尚未释放，并非包版本不兼容。

**修复：** 保留已完成安装，等待句柄释放后重试同一项目虚拟环境安装。第二次成功，并通过导入和测试验证。

## 2. 元数据列被错误按数值处理

**现象：** 质量检查将 `country` 计入无法转换为数值的记录，导致正常数据出现错误告警。

**原因：** 数值列推断只排除了时间与少量标识列，没有明确区分新增的文本元数据。

**修复：** 将 `country`、`timezone`、`source` 和摄取时间加入非数值列集合，并增加回归测试。

## 3. DuckDB 时区显示与 UI 标签不一致

**现象：** DuckDB 的 `TIMESTAMPTZ` 在本机会话中显示为 `+08:00`，Dashboard 却标注为 UTC。

**原因：** 查询结果继承本地会话时区，而展示标签假设数据已经转换为 UTC。

**修复：** 展示前显式转换为 UTC，再格式化为带 `Z` 的时间；截图复核显示一致。

## 4. Streamlit 默认主题颜色污染指标语义

**现象：** 默认红色强调与 AQI 风险红色含义冲突，图表颜色也不统一。

**原因：** 未设置应用主题且 Plotly 使用默认调色板。

**修复：** 增加项目级 Streamlit 主题，并为折线、状态和 AQI 显式定义颜色映射。
